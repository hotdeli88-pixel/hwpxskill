# 표 스타일 복제 (`table-style`)

원본 표의 **스타일만** 대상 표에 입힌다. 대상 표의 글·행·열·병합은 그대로다.

```bash
hwpx analyze 문서.hwpx                                   # 표 주소 확인 (s0.t0, s0.t1 …)
hwpx table-style 문서.hwpx --from s0.t0 --to s0.t2 s0.t3 -o 결과.hwpx
hwpx table-style 대상.hwpx --source 견본.hwpx --from s0.t1 --to s0.t0 -o 결과.hwpx   # 다른 문서의 표를 견본으로
```

## 역할 기준으로 맞춘다

행·열 수가 달라도 역할끼리 짝지어 입힌다.

| 역할 | 원본에서 찾는 법 | 옮기는 것 |
|---|---|---|
| 머리행 | 첫 행이 라벨 모양이거나 `header` 표시 | 배경, 글자 모양, 정렬 |
| 라벨 열 | 첫 열이 라벨(구분·항목…) | 배경, 글자 모양, 정렬 |
| 본문 | 나머지 칸 | 배경, 글자 모양, 정렬·줄 간격 |
| 합계행 | 첫 칸이 `합계·계·소계·총계·누계` | 배경, 글자 모양 |

| 선 | 뜻 |
|---|---|
| 바깥 테두리 | 위·아래·왼쪽·오른쪽 따로 |
| 안쪽 가로선·세로선 | 본문 칸 사이 |
| 머리행 아래선, 머리행 안 세로선 | 이중선 등 |
| 라벨 열 오른쪽 선 | |
| 합계행 위선 | |

그 밖에 세로 정렬, 셀 여백, 표 바깥 여백·셀 간격, 머리행 반복 설정, 그리고 **열 수가 같으면 열 너비 비율**(표 전체 너비는 대상 그대로)을 옮긴다. 너비를 건드리지 않으려면 `--keep-widths`.

- 대상 표가 `성명 │ 홍길동`처럼 **라벨-값 두 열** 표이면 머리행을 만들지 않고 라벨 열·본문 역할만 입힌다.
- 글자 모양은 역할의 대표 모양을 입히되, 대상 칸 안에서 일부만 굵게 한 강조는 살린다.
- 다른 문서에서 가져오면 글꼴·글자 모양·문단 모양·테두리 정의를 대상 문서로 옮기면서 번호를 새로 매기고, 같은 정의가 이미 있으면 다시 쓰지 않는다.

## 언제 쓰나

- 기관 서식의 표 모양(머리행 음영, 이중선)을 새로 채운 다른 표들에도 똑같이 맞출 때
- 다른 해 보고서의 표 모양을 이번 보고서 표에 입힐 때

## 확인할 것

PDF에서 선 굵기·배경색·머리행 글자색이 원본과 같은지, 열 너비가 바뀌어 글이 넘치지 않는지 본다. 넘치면 `--keep-widths`로 다시 한다.
