# 공문서 표기법·개조식 문체

`hwpx lint 값.json` (표기법), `hwpx lint 값.json --munche` (+개조식 문체). 문서 전체는 `hwpx lint 결과.hwpx`.
규칙은 [kordoc](https://github.com/chrisryugj/kordoc)(MIT)의 공문서 검사 규칙을 옮긴 것이다 (행정업무운영 편람·한글 맞춤법 기준).

## 문서 종류별 틀

### 기안문 본문 (행정업무운영 편람)
```
1. 관련: ○○과-1234(2026. 9. 1.)
2. 위 호와 관련하여 2026학년도 디지털 교육 운영 계획을 다음과 같이 보고합니다.
  가. 사업명: 디지털 교육 운영
  나. 기간: 2026. 10. 1.∼12. 31.
  다. 대상: ○○학교 1∼3학년 학생 000명
```
- 항목 순서: 1. → 가. → 1) → 가) → (1) → (가) → ① → ㉮ (하위로 갈수록 2타씩 들여쓰기 — 엔진이 처리)
- 붙임은 `붙임  1. 운영 계획 1부.` `2. 예산서 1부.  끝.` — 양식에 `붙임`·`끝.`이 이미 있으면 값에서 빼기.
- 본문 끝에 `  끝.` (붙임이 있으면 붙임 끝에).

### 개조식 보고서·계획서
```
□ 추진 배경
 ○ (현황) 학령인구 감소로 학급당 학생 수 20명 이하 학교 비율 확대
  - 2025년 43.2% → 2026년 47.8% (교육통계)
 ○ (정책) AI 디지털교과서 도입에 따른 수업 방식 전환 필요
□ 추진 목표
 ○ 학생 참여형 수업 비율 60% 이상
```
- `□` 제목 → `○` 내용 → `-` 근거·세부 → `·` 보충. 문장은 명사형(`~함`, `~필요`, `~확대`)으로 끝낸다.
- 첫 문단 리드문: `디지털 기반 수업을 확대하여 학생 맞춤형 교육을 실현하고자 함.`
- `(현황)`, `(정책)` 같은 괄호 머리말은 예시 서식이 굵으면 굵게 들어간다.

### 가정통신문·안내문
- 인사말 → 안내 내용(일시·장소·대상·준비물을 `○`나 표로) → 문의처 → 날짜·학교장. 존댓말 서술형(`~습니다`)이 자연스러우므로 `--munche` 없이 표기법만 검사한다.

## 사실 확인이 필요한 값
기관명, 문서번호, 날짜, 금액·예산, 인원, 통계 수치, 사람 이름·직위, 연락처는 사용자 자료에서만 가져오고, 없으면 `○○○`, `0000. 0. 0.`, `000명`, `000,000원`으로 둔 뒤 보고한다.
