# 양식 채우기 (`fill`)

## 값 JSON

```json
{
  "values": {
    "제목": "2026학년도 디지털 교육 운영 계획 보고",
    "기관명": "○○교육청",
    "작성일": {"value": "2026-09-28", "format": "date:yyyy. m. d."},
    "성명": ["홍길동", "김철수"],
    "성별": "남",
    "동의": "☑",
    "추진 배경": "□ 교육 환경 변화\n ○ 학령인구 감소로 학급당 학생 수 감소\n  - 2025년 대비 3.2% 감소"
  },
  "cells":     {"s0.t1.r2.c1": "□ 운영 방향\n ○ 학생 참여형 수업 확대", "s0.p12": "문단 전체를 바꿀 글"},
  "rows":      {"s0.t2": [{"연번": "1", "성명": "홍길동", "학년": "3"}, {"연번": "2", "성명": "김철수", "학년": "2"}]},
  "equations": {"0": "{a+b} over {2}", "x^2 + 1": "x^3"},
  "options":   {"require_unique": false}
}
```

| 키 | 쓰임 |
|---|---|
| `values` | 이름으로 찾아 채움. 아래 순서로 자리를 찾는다 |
| `cells` | 주소로 바로 채움: 표 셀 `s0.t1.r2.c1` 또는 본문 문단 `s0.p12`(문단 글 전체를 바꿈) |
| `rows` | 명단표 채우기. 키는 표 주소. 행은 `{머리행 이름: 값}` 또는 열 순서 배열 `["1", "홍길동", "3"]` |
| `equations` | 기존 수식 바꾸기. 키는 `equation list` 번호 또는 바꿀 수식 스크립트(일부) |
| `options.require_unique` | 같은 값이 여러 라벨 자리에 들어가면 경고 |

### `values` 이름 찾기
1. 누름틀 이름 → 2. `{{키}}`·`${키}` → 3. 표 라벨 칸(오른쪽 칸에 값) → 4. 본문 `라벨: ___` → 5. 체크박스·괄호 빈칸
- 이름은 띄어쓰기·쌍점·괄호·가운뎃점을 빼고 비교한다 (`"성 명"` = `"성명:"`). 표 라벨은 앞부분 일치도 허용한다 (`"연락처(휴대전화)"` ← `"연락처"`).
- **문자열 값**은 같은 이름의 모든 자리에, **배열 값**은 문서 순서대로 하나씩 들어간다.
- 같은 자리를 두 방법이 노리면 우선순위: `cells` > `rows` > 누름틀 > `{{}}` > 표 라벨 > 본문 라벨 > 체크박스·괄호. 진 쪽은 보고서의 `건너뜀`에 나온다.
- `안 쓰인 키`가 있으면 이름이 틀린 것이다 — `analyze`에 나온 이름을 그대로 쓰거나 `cells` 주소를 쓴다.

### 값 서식 (`{"value": …, "format": …}`)
| format | 예 |
|---|---|
| `date:yyyy. m. d.` (기본) · `date:yyyy년 m월 d일` · `date:yyyy-mm-dd` | `20260928` → `2026. 9. 28.` |
| `phone` · `phone:dot` · `phone:digits` | `01012345678` → `010-1234-5678` |
| `rrn` · `rrn:masked` · `rrn:front` | → `900101-1******` |
| `mask:###-##-#####` | 숫자를 # 자리에 |
| `digits` · `upper` · `lower` · `nospace` | |

## 자리 종류별 규칙

| 자리 | 양식 모습 | 값 | 결과 |
|---|---|---|---|
| 누름틀 | 안내문이 든 필드 | `"제목": "…"` | 필드 안 글을 바꾸고 `dirty` 표시. 여러 문단 값이면 필드가 여러 문단으로 늘어남 |
| 자리표시 | `{{기관명}} 운영 계획` | `"기관명": "…"` | 글자 서식이 여러 조각으로 나뉘어 있어도 바꿈. 문단 전체가 `{{본문}}`이면 여러 문단으로 채울 수 있음 |
| 표 라벨 | `성명 │ (빈칸)` | `"성명": "홍길동"` | 오른쪽 칸 서식(예시가 있으면 예시 서식)으로 채움 |
| 명단표 | 머리행 + 빈 행 | `rows` | 행이 모자라면 마지막 데이터 행을 서식째 복제해 늘림. 남는 빈 행은 그대로. 맨 끝 `합계·계·소계` 행은 데이터 행에서 뺌 |
| 본문 라벨 | `신청인: ______ (서명)`, `금액: ____원` | `"신청인": "홍길동"` | 밑줄·빈칸 자리에만 넣고 뒤의 `(서명)`·단위는 남김. `성별: □남 □여`처럼 선택지면 체크박스로 처리 |
| 체크박스 | `성별 □남 □여` | `"성별": "남"` 또는 `"남": "☑"` | □ → ☑. 여러 개는 `"남, 여"`. 선택지 하나뿐인 묶음(`동의 여부 □동의`)은 `"예"`도 됨. 표 칸이 선택지뿐인데 값이 선택지에 없으면 칸을 지우지 않고 건너뜀 |
| 괄호 빈칸 | `일반(  )통`, `(한자：  )` | `"일반통": "3"`, `"한자": "金哲洙"` | 괄호 안에 넣음 |

누름틀·자리표시는 **앞뒤 글과 이어진다.** `analyze`의 `⟨붙임 ▢ 1부.  끝.⟩`처럼 뒤에 `1부.  끝.`이 이미 있으면 값은 `운영 계획서`만 쓴다.

## 여러 줄 값 — 서식을 갖춘 내용

값에 줄바꿈(`\n`)이 있거나 `<eq block>`이 있으면 문단 여러 개로 쓴다. **마크다운이 아니라 한글 문서 부호**로 단계를 나타낸다.

```
□ 추진 배경
 ○ 학령인구 감소로 학급당 학생 수 감소
  - 2025년 대비 3.2% 감소 (교육통계연보)
 ○ (정책 변화) AI 디지털교과서 도입
※ 세부 일정은 붙임 참고
```

- **부호**: `□ ■ ○ ❍ ㅇ ● ◦ - · ※ * ⇒ ▶`, 번호 `1. 가. 1) 가) (1) (가) ① ㉮ Ⅰ. ㄱ.` — 부호 뒤에는 **반드시 한 칸** (`○○부`, `1.5배`는 부호가 아님).
- **단계**는 부호로 정해진다: 공문서 번호는 1. → 가. → 1) → 가) → (1) → (가) → ① → ㉮, 보고서 부호는 Ⅰ. → □ → ■ → ○ → ❍ → ㅇ → ● → - → ◦ → · 차례에서 실제로 쓴 것끼리 위아래를 매긴다. `※`는 앞 줄보다 한 단계 아래. 줄 앞 공백은 읽기 좋게 넣는 것일 뿐이다.
- 부호 없는 줄은 보통 문단이 되고, 줄 앞에 공백이 있으면 앞 줄 단계에 맞춰 이어 쓰는 문단이 된다.
- **서식 출처** (자동):
  1. 같은 셀·필드에 예시로 쓰인 문단이 있으면 → 부호별로 그 문단 모양·글자 모양을 그대로 쓴다. 예시에서 `(배경)`·`[목표]`·`추진 배경:` 같은 머리말만 굵게 했다면 같은 꼴로 쓴 머리말도 굵게 들어간다.
  2. 같은 표·문서의 다른 예시 셀
  3. 예시가 없으면 첫 문단의 글꼴·크기·줄간격에, 단계마다 1글자씩 들여쓰고 부호 폭만큼 내어써서 둘째 줄이 글자 시작에 맞춰지게 한다.
- 예시 글은 새 내용으로 **바뀐다** (예시를 남기려면 그 셀을 채우지 않는다).
- 값 안의 `\t`는 탭으로 들어간다. 줄바꿈은 언제나 새 문단이다.
- 수식: `"값은 <eq>{1} over {2}</eq>이다"`(글 속), `"<eq block>sum _{k=1} ^{n} k = {n(n+1)} over {2}</eq>"`(한 줄 가운데).

## 내용 쓰기 요령

- 칸 크기를 본다: `analyze --outline`의 셀 글 길이, 예시 분량과 비슷하게 쓴다. 한 칸에 너무 길면 PDF에서 넘친다.
- 사실 정보(사람 이름·날짜·금액·연락처·문서번호·통계 수치)는 사용자 자료에서만 가져온다. 없으면 `○○○`, `0000. 0. 0.`, `000,000원`으로 두고 보고한다.
- 쓴 값은 `hwpx lint 값.json --munche`로 검사한다. 오류(날짜·시간·금액 표기, `~다` 종결 등)는 고치고, 경고는 판단해서 고친다.

## 보고서 읽기 (`--dry-run`, `--json`)

- `filled`: 채운 자리(`kind`, `location`, 값 요약)
- `skipped`: 못 채운 자리와 이유 → 반드시 해결하거나 사용자에게 알림
- `unmatched_keys`: 어디에도 안 쓰인 키 → 이름 오타
- `rows_added`: 늘린 행 수와 복제한 행
- `warnings`/`notes`: 배열 값이 남음, 행을 못 늘림, 수식 경고 등
- `--strict`: 건너뜀·안 쓰인 키가 있으면 종료 코드 2
