# 시험지·학습지 (`exam`)

```bash
hwpx exam -d 문항.json -o 시험지.hwpx                  # 내장 스타일로 새로 만들기
hwpx exam -d 문항.json -t 학교양식.hwpx -o 시험지.hwpx   # 학교 양식에 채우기
```
저장 뒤 자동 검수(구조·수식·PDF)까지 한다. 그림 넣기, 정답·해설지는 아직 지원하지 않는다.

## 문항 JSON

```json
{
  "title": "2026학년도 2학기 기말고사",
  "subject": "수학", "grade": "1학년",
  "fields": ["학년", "반", "번호", "성명"],
  "notice": "※ 답은 답안지에 표기하시오. 계산기는 사용할 수 없습니다.",
  "columns": 2,
  "questions": [
    {"text": "<eq>{1} over {2} + {1} over {3}</eq>의 값은?", "points": 3,
     "choices": ["<eq>{1} over {6}</eq>", "<eq>{2} over {5}</eq>", "<eq>{5} over {6}</eq>", "1", "<eq>{7} over {6}</eq>"]},
    {"text": "다음 중 옳은 것만을 <보기>에서 있는 대로 고른 것은?", "points": 4,
     "box_title": "<보 기>", "box": "ㄱ. <eq>sqrt {4} = 2</eq>\nㄴ. <eq>(-3)^2 = -9</eq>\nㄷ. <eq>left | -5 right | = 5</eq>",
     "choices": ["ㄱ", "ㄴ", "ㄱ, ㄷ", "ㄴ, ㄷ", "ㄱ, ㄴ, ㄷ"]},
    {"text": "함수 <eq>f(x) = 2x + 1</eq>에 대하여 <eq>f(3)</eq>의 값을 구하는 과정을 서술하시오.\n(단, 풀이 과정을 모두 쓰시오.)",
     "points": 5, "space": 6}
  ]
}
```

| 키 | 뜻 (기본값) |
|---|---|
| `title`, `subject`, `grade` | 머리 제목, 과목·학년 줄 (새로 만들 때) |
| `fields` | 머리 표 칸 (`["학년","반","번호","성명"]`) |
| `notice` | 머리 아래 안내 문구 |
| `columns` | 단 수 (2) |
| `column_line` | 단 구분선 (false — 켜면 머리 표를 가로지를 수 있음) |
| `size`, `font` | 본문 글자 크기 pt (10), 글꼴 (함초롬바탕) |
| `points_format` | 배점 표시 (`"[{n}점]"`) |

문항 키:

| 키 | 뜻 |
|---|---|
| `text` | 문항 글. `\n`으로 줄을 나누면 이어지는 문단(배점은 마지막 줄 끝) |
| `points` | 배점 (3, 3.5) |
| `choices` | 보기(보통 5개). ①~⑤ 번호는 자동 |
| `choice_layout` | 한 줄에 놓을 보기 수 (1·2·3·5). 없으면 길이로 자동 |
| `box`, `box_title` | <보기>·제시문 상자 (여러 줄은 `\n`) |
| `space` | 서술형 풀이 칸(빈 줄 수) |
| `number` | 문항 번호를 직접 지정 (없으면 1부터) |

수식은 `<eq>…</eq>` 안에 한글 수식 스크립트로 쓴다 ([equation.md](equation.md)). LaTeX가 섞이면 만들기 전에 오류로 멈춘다.

## 보기 자동 배치

보기 글의 폭(수식은 크기를 추정해서)을 재서 단 폭에 맞게 고른다: 한 줄에 5개 → 3개+2개 → 2개씩 → 한 줄에 하나. 탭 위치를 맞춰 세로로 가지런하다. 특정 배치를 원하면 `choice_layout`.

## 양식 채우기 모드 (`-t`)

양식에서 문항 자리를 이 순서로 찾는다.
1. `{{문항}}`만 있는 문단 → 그 자리에 문항을 넣는다.
2. **예시 문항** (번호로 시작하는 문단 `1. …` + 12문단 안의 ①~⑤) → 예시의 문항 번호 글자 모양, 번호 뒤 간격(탭/공백), 문단 모양, 보기 문단·글자 모양을 익히고, 예시 문항들을 새 문항으로 **바꾼다**.
3. 둘 다 없으면 본문 끝에 붙인다.

1단 양식이면 첫 문항부터 2단으로 바꾸고, 문항 뒤 내용(맺음말 등)은 원래 단 수로 되돌린다. 머리 표·학교명·안내문은 양식 그대로 둔다 (필요하면 먼저 `fill`로 채운 뒤 `exam -t`).

## 새로 만들기 모드의 모습

A4, 여백 15mm, 머리 표(제목·과목·칸·안내)는 종이 위에 고정되고 두 단은 그 아래에서 시작한다. 문항 번호는 굵게, 문항 글은 번호 뒤에 내어쓰기로 줄 맞춤, 문항 사이 간격, 보기는 문항 글 시작 위치에 맞춘다.

## 확인할 것

- PDF에서 보기가 줄을 넘지 않는지, 수식이 잘리지 않는지, 문항이 단 끝에서 어색하게 나뉘지 않는지 본다.
- 미리보기(rhwp) 한계: 1단 양식을 문서 중간에서 2단으로 바꾼 경우 rhwp는 **수식이 든 문단**을 첫 단 설정 폭으로 그려 오른쪽으로 넘쳐 보일 수 있다 (한글에서는 정상). 새로 만들기 모드는 처음부터 2단이라 해당 없음.
- 정답은 문서에 넣지 않는다. 사용자가 원하면 대화로 따로 알려 준다.
